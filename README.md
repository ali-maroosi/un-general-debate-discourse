# Diplomatic Discourse in the UN General Debate

A comparative computational analysis of diplomatic discourse
in United Nations General Debate speeches from Iran,
the United States, and China (1972–2025).

## Overview
This research examines historical changes in diplomatic
language using natural language processing and statistical
analysis.

## Methods
- Text preprocessing and exploratory analysis
- TF-IDF and non-negative matrix factorization (NMF)
- Historical comparisons of topic shares
- Newey-West HAC inference
- Multiple-testing correction and robustness checks
- Historical sensitivity analysis of Iran's 1979 revolution

## Repository Structure
- `notebooks/` — Research analysis notebooks
- `environment.yml` — Computational environment

## Data
The study uses the United Nations General Debate Corpus
(UNGDC, 1946–2025). Raw data and intermediate research
outputs are not included in this repository.
